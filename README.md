# Varnika Singh — Portfolio

An overview of my professional journey so far.

A single-page static portfolio (HTML, CSS and vanilla JS) hosted on GitHub Pages.

## Structure

| Path | Purpose |
|---|---|
| `index.html` | The whole site: Home, Skills, Experience, Education, Projects, Contact |
| `photos/` | Profile photo and slideshow images (lowercase filenames, web-optimised JPEGs) |

## Design

Deep navy backgrounds with teal accents; colours are defined as CSS variables at the top of `index.html`.
